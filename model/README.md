# Model

Core model and data-loading implementation.

## Files
- `dataloader.py`: data loading, normalization, and graph/node feature assembly.
- `utils.py`: scaling utilities and metric definitions.
- `model_full.py`: full Mukara architecture.
- `model_no_edge_features.py`: ablation without edge-feature branch.
- `model_only_edge_features.py`: ablation using only edge features.
